Implement Phase 1 Task 6 only: improve the Pub and Review experience in Pint Wars.

The existing pub and review functionality works. This task is a UX/product-polish improvement only.

LOCKED SCORING:
- 1 logged pint = +1 point
- Qualifying pub review = +1 bonus point
- No new-pub bonus
- Review bonus only once per player per pub
- Editing a review = +0
- Deleting and recreating a review = +0
- Review reports = +0

Do NOT change these rules.

PUB EXPERIENCE:

- Which pub they are looking at
- Location/details where available
- Overall rating
- Number of reviews
- Relevant pub information already available
- Their own relationship with the pub where existing data supports it

Where existing data supports it, show useful Pint Wars context such as:
- Whether the user has visited/logged a pint there
- Their review
- Their review status/eligibility
- Relevant Pint Wars activity

Do not invent information that isn't available.

REVIEWS:

3. That a qualifying review awards +1 bonus point.
4. That the bonus is awarded only once.
5. Editing does not award another point.
6. Deleting/recreating cannot generate another bonus.

Do not change backend scoring enforcement. This is presentation only.
